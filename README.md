A clean, responsive 🌦️ **Weather App** that lets you check the current weather conditions of any city in the world in real-time.  
Built using **HTML**, **CSS**, and **JavaScript** — simple yet effective front-end web application.  

---

## 🚀 Features
✨ Fetches live weather data using an external API  
🌍 Displays temperature, humidity, and weather condition  
🎨 Simple and user-friendly interface  
⚡ Fast, lightweight, and responsive design  
☁️ Error handling for invalid cities or API issues  

---

## 🧠 Technologies Used
| Technology | Purpose |
|-------------|----------|
| **HTML5** | Structure of the app |
| **CSS3** | Styling and layout |
| **JavaScript (ES6)** | Logic, API calls, and dynamic updates |
| **Weather API** *(e.g., OpenWeatherMap)* | Fetching real-time weather data |
